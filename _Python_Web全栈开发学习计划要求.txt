
Python Web 全栈开发学习计划要求
一、学习目标
基本掌握 Python Web 开发所需的核心技术，能够在人工智能工具辅助下，完成包含前端页面、Python Web API、ORM 数据访问和数据库持久化的小型应用，并具备通过后续工作实践持续提升能力的基础。
二、技术栈方向
范围
技术栈方向
后端
Python 3.11 或更高版本、FastAPI、Pydantic 2、SQLAlchemy 2、Alembic
前端
Vue 3、TypeScript、Vite、Vue Router、TanStack Query、Zod
版本管理
Git
前端技能学习不包含在本计划内。综合实践阶段使用上述前端技术栈完成页面开发和前后端接口联调。
三、必须学习的技术点
1. Python 基础
Python 开发环境、虚拟环境和依赖管理。
变量、常用数据类型、条件、循环、函数和常用集合。
类、对象、模块、包和项目代码组织。
类型标注及常用 typing 能力。
异常处理、JSON、文件读写等常用能力。
async/await 的基本概念和使用方式。
2. Web 与 HTTP 基础
HTTP 请求与响应的基本结构。
常用 HTTP 方法和状态码。
路径参数、查询参数、请求头、请求体和 JSON。
REST 风格接口的基本设计原则。
浏览器同源策略、跨域和身份信息传递的基本概念。
3. FastAPI 与 Pydantic
创建、启动和组织 FastAPI 应用。
使用 APIRouter 划分接口和业务模块。
定义接口参数、请求模型和响应模型。
字段类型、默认值、约束和输入校验。
返回结构、状态码和异常响应。
依赖注入以及同步、异步接口的基本使用。
使用 OpenAPI/Swagger 文档验证接口。
4. ORM 与数据持久化
使用 SQLAlchemy 2 建立数据库连接和会话。
使用 ORM 模型定义数据表映射、字段、主键、约束和基本关联关系。
通过 ORM 完成新增、查询、修改、删除和分页。
理解 Session 生命周期和基本事务边界。
使用 Alembic 创建、执行和管理数据库结构迁移。
区分接口模型和 ORM 模型。
5. 前后端集成
从前端调用 Python Web API。
处理加载、成功、空数据和失败状态。
完成表单数据提交、响应展示和错误提示。
保持前端数据结构与后端请求、响应模型一致。
使用浏览器开发者工具和服务端日志定位联调问题。
6. Git 版本管理
所有涉及编码的练习和综合实践必须使用 Git 进行版本管理。
按功能或学习阶段持续提交代码，提交说明应准确描述修改目的。
能够基本使用分支、合并和冲突处理。
仓库应包含 README，说明环境要求、安装步骤、启动方法和主要功能。
不得向仓库提交密码、Token、私钥、真实业务数据及其他敏感信息。
7. 人工智能辅助开发
向人工智能工具提供清晰的目标、上下文、约束和验收条件。
使用人工智能工具辅助解释代码、生成初稿、排查错误和检查变更。
对生成内容进行人工审阅和实际运行验证。
能够说明关键代码的作用、数据流和主要设计选择。
不得向未经批准的工具提交公司密钥、账号口令、生产数据及其他敏感信息。

五、综合实践要求
实践选题：待定。
学习人员应完成一个小型前后端应用，形成从页面操作、接口调用、后端处理到数据库持久化的基本开发闭环。
使用规定的前端技术栈完成可操作页面。
使用 FastAPI 提供真实的 Python Web API。
使用 Pydantic 定义并校验请求和响应数据。
使用 SQLAlchemy ORM 完成数据库访问和数据持久化。
使用 Alembic 管理数据库结构迁移。
至少实现新增、查询、修改、删除中的三类业务操作。
正确展示加载、成功、空数据和失败状态。
使用 Git 管理全部代码和开发过程。
提供完整的 README 和本地运行说明。

七、完成标准
满足以下条件，可视为完成本阶段学习要求：
□　能够创建 Python 虚拟环境、安装依赖并启动 FastAPI 服务。
□　能够使用 FastAPI 和 Pydantic 实现基础 HTTP API。
□　能够使用 SQLAlchemy ORM 完成数据访问和数据库持久化。
□　能够使用 Alembic 管理数据库结构迁移。
□　能够完成前端页面、Python API 与数据库的真实联调。
□　能够借助人工智能工具完成部分开发工作，并对最终实现负责。
□　能够说明实践项目中的主要请求流程、数据流和关键代码。
□　全部代码已使用 Git 管理，并具备清晰的提交记录和可用的 README。
八、成果提交
Git 仓库地址或指定的仓库交付方式。
可运行的前端、Python 后端和数据库相关代码。
数据库迁移文件。
项目 README 及必要的运行配置示例。
简短的实践说明，包括已实现功能、运行方式和人工智能工具的主要使用方式。
